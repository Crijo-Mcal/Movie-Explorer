🎬 Movie Explorer

This is my first Movie Explorer web application, which allows users to explore movies from around the world. Users can search for movies by title and view details such as synopsis, rating, release date, and poster.

✨ Key Features

🔍 Movie Search: Quickly find movies by title.
🎬 Detailed Movie Information: View details like poster, synopsis, genre, and rating.
🌐 TMDB API Integration: Fetch real-time movie data from The Movie Database (TMDB)
💾 Responsive Design: Modern, lightweight interface that works seamlessly on all devices.

🛠️ Technologies Used

Frontend: Vite, React, Tailwind CSS, PrimeReact
API: TMDB API
Tools: VS Code, Git, GitHub
